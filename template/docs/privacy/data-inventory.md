# Data Inventory

## How to complete this document

List every category of personal data this application processes: what it is, whose it is,
why you hold it, on what lawful basis, where it lives and how long you keep it. The
starter's own data is pre-filled — verify it, then add every project-specific category.
This inventory feeds the DPIA screening, the retention schedule and subject-rights
handling, so keep the category names consistent across the privacy set. Completing this
document is a deferred control in the control manifest; assign the owner there and here,
then set `status: complete` with a review date. Review at least annually and on every
schema change that adds personal data.

> This template supports evidence gathering; it does not by itself provide ISO 27001,
> SOC 2, Cyber Essentials, WCAG conformance or legal compliance.
